# Security Policy

## Supported Versions

Security updates and critical vulnerability patches are applied to the latest release of Portila.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential threat within Portila:

1. **Please do NOT disclose it publicly** in public GitHub issues or discussions.
2. Report the vulnerability privately via **GitHub Private Vulnerability Reporting** on this repository, or email the maintainers directly at `codingpenin@gmail.com`.
3. Please include:
   - A description of the issue and potential impact.
   - Minimal reproduction steps, proof of concept (PoC), or crash report.
   - Affected components (`pkg/server`, `pkg/relay`, `pkg/tls`, etc.).

### Our Commitment
- We will acknowledge receipt of your report within **48 hours**.
- We will work closely with you to validate, patch, and release a fix in a timely manner.
- Credit will be given to the finder in the release notes (unless anonymity is requested).
